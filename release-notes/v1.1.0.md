RedMagic Tweaks 1.1.

**Made for:** REDMAGIC 10S Pro / 10 Pro (NX789J) on Android 16. Developed on the China firmware (RedMagic OS 11.0.11).
Every hook was checked against the global / EEA firmware (11.0.4). The few tweaks that only work on China firmware
(Phone Manager, Magic Voice, screen cast extras, the Chinese installer) are hidden on global.

### What changed
- **The One UI layouts are gone**: the one-tap One UI 8 look, the One UI 8 Control Center layout, the One UI lock screen
  and AOD clocks, the One UI 8 volume panel and power menu, and the One UI System UI font. If you used them, the app
  resets those settings once after the update and asks you to restart System UI, which brings back the stock look.
  Everything else you set up stays.
- **Every customization stays**: Control Center columns, gaps, sliders and colours, the lock screen clock and date
  (now with colours), the volume bar (width, height, shape, colours, icon, level, side, position, timeout), the power
  menu (button finish, position, layout, dim), the status bar, notifications, AOD, launcher, recent apps styles,
  fingerprint and charging animations, Game Space and system tweaks.
- **Logs**: a Record logs switch (off = nothing is recorded), and Share as .txt file / Save .txt to Download.

### Install
1. Install the APK below over v1.0, or fresh.
2. In LSPosed, enable RedMagic Tweaks and tick every app in its scope.
3. Reboot once, then open the app.

Credits are in the app (About) and in the README.
