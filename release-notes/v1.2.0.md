RedMagic Tweaks 1.2.

**Made for:** REDMAGIC 10S Pro / 10 Pro (NX789J). Checked on the global firmware (RedMagic OS 11.0.4MR1, Android 16)
and the China firmware. The few China-only tweaks (Phone Manager, Magic Voice, screen cast extras, the Chinese
installer) stay hidden.

### What's new
- **Русский язык**: ⋮ → **App language** switches the whole app to Russian. Every sentence is Russian before the screen is drawn. English stays available the same way.
- **The One UI layouts are back**: the one-tap One UI 8 look, the One UI 8 Control Center, the One UI lock screen and
  AOD clocks, the One UI 8 volume panel and power menu, the One UI System UI font, and the drawer's own app order with
  fixed slots.
- **Gaming**: frame interpolation in every game with its target refresh rate · game full screen · Game view (wider
  view in PUBG-style games) · every Game Space plugin in every game · launch boost · Game Assist defer · Game Lab AI
  speed (the last three are experimental).
- **Lock screen & AOD**: your own video on the lock screen and on the always-on display · AOD clock position.
- **Battery & charging**: the battery health page · charge separation at 100 % · the China firmware's charging
  animations: Black Myth: Wukong golden staff (each stage), Wuthering Waves CAMELLYA pink lotus, blue ring and the
  green crystal cube · "Follow the theme" (the CAMELLYA and Black Myth themes bring their own charging animation).
- **Launcher**: icon packs (installed apps, or a zip / theme file, plus two built-in One UI 8 icon sets) · icon shape · icon size · label size · hidden labels
  · folder columns and rows. Icon pack and icon shape also apply on third-party launchers, including One UI Home
  (`com.sec.android.app.launcher` must be ticked in LSPosed).
- **Android 15 China (10.5.6 / 10.5.8)**: brightness bar shape, Game Space Free display ratios, and the older names
  for theme lists and fingerprint gates.
- **System**: Google international mode.
- Many fixes from RM Tweaks: charging animations now play on global firmware, previews of the stock charging sets,
  option sheets scroll properly, quieter logs.

### Still not included
USB debugging auto-allow, untrusted touches, no 72-hour lock and volume boost (they weaken security or can damage the
speakers).

### Install
1. Install the APK below over v1.1, or fresh.
2. In LSPosed, enable RedMagic Tweaks and tick every app in its scope.
3. Reboot once, then open the app.

Credits are in the app (About) and in the README.
